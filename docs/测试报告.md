## 1. 测试概述

本报告覆盖成员 C 主责的前端工作包（WP-05 掩膜编辑器与标注工作台、WP-09 筛查工作台与报告前端、WP-11 统计看板）以及平台基础页面。由于成员 A 的 `backend/` 尚未交付，本阶段采用 **Mock 数据层**（`src/api/mock.ts`，对齐 `接口规范.md` 63 个接口契约）验证前端完整主链路；后端就绪后将 `VITE_USE_MOCK` 置为 `false` 即可切换真实接口，并补充真实 E2E、性能与安全测试。
